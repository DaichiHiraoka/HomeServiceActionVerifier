# この研究の全体像

## ひとことで言うと

**留守中に家に入って作業する人（修理業者など）を、「顔や姿を撮らずに」見守り、あやしい動きがあれば気づける仕組みを作り、それが本当に可能かを実験で確かめる研究。**

## どんな困りごとから始まったか

家電の修理などで業者を家に呼ぶとき、ずっと立ち会うのは面倒くさい。かといって、知らない人を家にひとりにするのは不安が残る。実際、訪問先の家でお金や貴重品が盗まれる事件は全国でくり返し起きている。

いちばん簡単な対策は監視カメラを置くことだが、これには大きな問題がある。働く人をずっと撮り続けるのは気分のいいものではないし、録画した映像が流出したり、のぞき見されたりした事件も実際に起きている。海外では、カメラ会社の社員が客の寝室の映像を大量にのぞいていたことが発覚し、大問題になった。調査でも「他人を家に入れたくない」がサービスを使わない理由の上位に入り、「カメラは嫌だが、人形のような抽象的な映像なら受け入れられる」という声が多いことがわかっている。

つまり、**「確認はしたい。でも撮られ続けるのは嫌だ」という板ばさみ**が世の中に実在する。この研究はその板ばさみを解くことを目指す。

## アイデアの核心

カメラの映像をそのまま残す代わりに、映像から**「棒人間」のような体の動きの情報だけ**を取り出して使う。顔も服装も部屋の様子も残らない。残るのは「関節がどう動いたか」という点と線の情報だけ。

ただし、体の動きだけでは「物を拾った」ことまでしかわからない。拾うこと自体は仕事中に何度もある普通の動作で、問題はその**前後**にある。

- 普通の流れ：拾う → 作業場所に持っていく → 使う、または元に戻す
- あやしい流れ：拾う → 体のそばに引き寄せる → 作業に戻らず出口の方へ

そこで、棒人間の動きに加えて、**触った物の位置の変化**（元の場所に戻ったか、部屋の外側へ運ばれたか）と、**動作の前後の流れ**を合わせて見る。「一瞬の動作」ではなく「流れ」で判断するのがこの研究のポイントである。

## 何を実験で確かめるのか

確かめたい問いはひとつ。

> 顔や部屋の映像を使わず、棒人間の動きと物の位置の変化だけで、「普通の作業」と「あやしい流れ」を見分けられるか？

そのために、模擬的な作業部屋を作り、協力者に演技をしてもらって動画を撮る。演技は「普通の作業」4種類と「あやしい動き」4種類。わざと**「普通なのに一見あやしく見える動き」**（道具を探しに出口の方へ歩いてから戻る、など)も混ぜる。これを入れないと、「出口に歩いた＝あやしい」という浅い丸暗記で正解できてしまい、本当に見分けられたのか分からなくなるからだ。

集めた動画で、次の比べっこをする。

1. 拾った瞬間だけを見て判断した場合 → たぶんあまり当たらない（そう予想している）
2. 前後の流れまで見て判断した場合 → こちらの方が当たるはず

「2 が 1 よりはっきり良い」と示せれば、仮説は支持されたことになる。さらに、**どれくらい早い段階で気づけるか**も測る。物を持ち去られてから分かるのでは遅く、部屋を出る前に警告が出せれば、悪いことを思いとどまらせる効果が期待できるからだ。

## 判断の公平さのために決めていること

- 判定プログラムを試すときは、**練習に使った人とは別の人**の動画で試す。知っている人の癖を覚えただけでは意味がないため。
- 「物を返したかどうか」のような答えに近い情報を、人間がこっそり書き込むことはしない。すべて棒人間と物の位置から機械が自分で計算する。
- 当たった・外れたの数字だけでなく、**間違えた動画を1本ずつ見て、なぜ間違えたのかを説明する**。

## 正直に言っておく限界

- 見抜けるのは「流れとして不自然な動き」であって、人の心の中や本当の犯罪ではない。実験も演技によるものである。
- 棒人間のデータも完全に匿名ではない。歩き方の癖から人を当てられる可能性が研究で指摘されている。ただし、顔・服装・部屋の様子が最初から存在しないという点で、普通の録画よりはるかに漏れて困る情報が少ない。
- 実験は「普通」と「あやしい」を半々で用意するが、現実にはあやしい行動はめったに起きない。実際に使うにはもっと誤報を減らす工夫が要る。

## この研究の価値

1. 「撮られたくない」と「確認したい」の板ばさみに対して、**そもそも映像を残さない**という解き方を、留守中の作業確認という新しい場面で示す。
2. その必要性を思いつきではなく、実際の事件・ルール・調査データで裏づける。
3. 「瞬間ではなく流れを見ると当たるようになるのか」を、条件をそろえた比べっこで確かめる。
4. 「何秒後に気づけるか」まで測り、事後の証拠ではなく**未然の防止**につながる可能性を検討する。

## 進め方（ざっくり年間予定）

| 時期 | やること |
| --- | --- |
| 7月 | 撮影の台本とカメラの位置を決めて固定する。先生と相談ごとを片づける |
| 8〜9月 | 協力者3〜5人と撮影（約120本）。撮ったその日に読み取り確認 |
| 9〜10月 | 動画に「いつ何を触ったか」の印つけ |
| 10〜11月 | 比べっこ実験と、間違いの分析 |
| 12〜1月 | 論文執筆と発表準備 |

判定の仕組み（プログラム）はすでに完成しており、あとは撮影とデータづくり、分析、執筆が残っている。
