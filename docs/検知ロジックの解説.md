# どうやって「あやしい動き」を見つけるのか — 仕組みの解説

むずかしい言葉を使わずに、判定の中身を順番に説明する。全体は6つのステップでできている。

```
動画 → ①棒人間にする → ②物の位置を追う → ③「触った前後」を切り出す
     → ④数字の特徴に変換する → ⑤お手本と比べて点数をつける → ⑥点数で警告を出す
```

---

## ステップ① 映像を「棒人間」にする

カメラの映像を1コマずつ調べて、体の33か所（肩・ひじ・手首・腰・ひざ・足首など）が画面のどこにあるかを点として記録する。これには公開されている既製の技術を使う。

このステップが終わった時点で、**映像そのものは判定に使わない**。残るのは「点の位置が時間とともにどう動いたか」という数字の表だけ。顔・服装・部屋の様子はこの表には含まれない。

人によって体の大きさやカメラからの距離が違うので、**肩幅を「ものさし」にして割り算**しておく。こうすると「大柄な人」と「小柄な人」の動きを同じ土俵で比べられる。

## ステップ② 物の位置を追いかける

財布や工具など、注目する物について「この時刻に画面のこのあたりにあった」という位置を記録する（実験では人が要所要所に印をつけ、間はプログラムが埋める）。

物についてわかるのは位置と大きさだけ。これに加えて、**物のまわりだけを小さく切り抜いた画像**の模様の情報を補助的に使う場合もあるが、切り抜きの大きさに上限を設けて部屋が写り込まないようにする。

## ステップ③ 「物に触った前後」を切り出す

一日中の動きを全部見るのではなく、**人が物に触った瞬間を中心に、前後数秒間だけ**を切り出して調べる。あやしいかどうかの情報は、触る前の近づき方と、触った後の振る舞いに集中しているからだ。

この「前後何秒を見るか」は実験の重要な比較ポイントで、0秒（触った瞬間だけ）から10秒まで変えて、どのくらいの長さが必要かを調べる。

## ステップ④ 切り出した場面を「数字の特徴」に変換する

ここが仕組みの心臓部。切り出した数秒間を、意味のある数字の集まりに変換する。数字は大きく5つのグループに分かれ、それぞれが「刑事の目のつけどころ」に対応している。

| 目のつけどころ | 具体的な数字の例 | 何を捉えたいか |
| --- | --- | --- |
| 体の動き方 | 移動の速さ、しゃがんだ回数、立ち止まっていた時間の割合 | そわそわした動き、不自然なしゃがみ込み |
| 物の動き | 物が最初の場所からどれだけ離れたか、動く速さ | 物が「あるべき場所」から離れていく様子 |
| 手と物の関係 | 手首と物の距離、物を持っていた時間、物と胴体の距離 | **物を体に引き寄せて隠す**動き（距離が縮んで縮んだまま） |
| 前後の流れ | 触った後に作業場所へ戻った割合、物が元の位置に戻ったかの距離、出口方向へ進む速さ | **作業に戻らない・返さない・持って出ようとする**流れ |
| 物のまわりの見た目 | 切り抜き画像の模様の変化 | 物が壊された・すり替わったなどの変化 |

大事なルールがひとつある。「返したかどうか」のような**答えに直結する情報を人間が書き込むことは禁止**で、上の数字はすべて棒人間の点と物の位置から計算だけで出す。人間が答えを教えてしまったら、当てられて当然になり実験にならないからだ。

### 具体例で見る

**普通の片付け**：財布を拾う → 手と財布の距離がいったん縮む → 棚に置く → 物の「最初の位置からの距離」がほぼゼロに戻る → 体は作業場所へ戻る（作業場所にいた割合が高い）

**あやしい持ち去り**：財布を拾う → 手と財布の距離が縮んだまま長く続く（持ちっぱなし）→ 財布と胴体の距離も小さいまま（体に引き寄せている）→ 物の「最初の位置からの距離」が増え続ける → 体と物が出口方向へ進む速さがプラスになる → 作業場所へ戻った割合はゼロ

同じ「拾う」で始まっても、数字の表にするとまったく違う形になる。これが「瞬間ではなく流れを見る」の正体である。

## ステップ⑤ お手本と比べて点数をつける

変換した数字を、**たくさんのお手本（普通の作業の例とあやしい動きの例）から学んだ判定器**に入れる。判定器は「たくさんの簡単な質問を組み合わせる多数決」のような仕組みで動く。イメージとしては：

- 質問1「物は最初の場所から遠くにあるか？」→ はい
- 質問2「触った後、作業場所に戻ったか？」→ いいえ
- 質問3「物を体の近くに長く保持したか？」→ はい
- …（こうした質問が何百個もあり、それぞれが少しずつ票を入れる）

質問の内容や「どの数字をどこで区切るか」は人間が決めるのではなく、**お手本のデータから自動的に学ばれる**。最終的に「あやしい票」の割合が **0〜1の点数**として出てくる（0.9なら「かなりあやしい」、0.1なら「ほぼ普通」）。

ここで公平さのための約束がある。判定器の実力を測るときは、**学習に使った人とは別の人の動画**で試す。ある人の癖を覚えただけでは、初めて見る作業者に通用しないからだ。

## ステップ⑥ 点数から警告を出す — 「早く気づく」工夫

点数が何点以上なら警告を出すか（しきい値）を決める必要がある。高くしすぎると見逃し、低くしすぎると誤報だらけになる。この研究では「**普通の作業を間違って警告するのは5回に1回まで**」という条件を先に決め、それを満たす中でいちばん敏感な値を、学習用のデータだけを見て選ぶ。

さらに、切り出した場面を最後まで見ずに、**途中まで（触る直前、触った直後、1秒後、3秒後…）の情報だけで点数を計算し直す**。すると点数の時間変化のグラフが描ける。

- 普通の作業：点数は低いまま推移する
- あやしい動き：物を体に引き寄せたあたりから点数が上がり始め、出口へ向かう頃には警告ラインを超える

警告ラインを超えた時刻を記録すれば、「持ち去りの何秒前に気づけたか」が測れる。**部屋を出る前に気づければ、その場で音を鳴らすなどして思いとどまらせる使い方につながる**。これがこの研究の最終目標（記録ではなく予防）と直結する部分である。

---

## まとめ：この仕組みの賢さと限界

賢さの源は、高度な人工知能というより**「どこを見れば流れの違いが出るか」という特徴の設計**にある。「返さない」「戻らない」「体に引き寄せる」「出口へ向かう」という人間の直感を、棒人間と物の位置から計算できる数字に翻訳したことが本体である。

限界も同じ場所にある。数字に翻訳されない種類のあやしさ（例：ポケットの中での細かい手の動き）は原理的に見えない。また判定器はお手本から学ぶので、お手本にない状況では間違える。だからこそ実験では「わざと紛らわしい普通の動き」を混ぜて、どこまで通用しどこで間違えるのかを正直に調べる。
