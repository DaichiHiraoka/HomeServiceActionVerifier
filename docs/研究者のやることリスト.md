# 研究者（自分）がやることリスト

道具（プログラム）はほぼ完成している。ここから先は、道具では代われない「人間の仕事」が中心になる。

## 1. いますぐ（7月前半）

- **先生に相談して決める（2つ）**
  - 「物のまわりの小さな画像も使う方式（条件F）」を研究に含めるか、外すか
  - 撮影で人に協力してもらうとき、大学の許可や同意書が必要かどうか
- **撮影の台本を確定させる**
  - ふつうの作業3〜4種類、あやしい動き3〜4種類。一度決めたら途中で変えない
  - 大事なコツ：「ふつうの作業なのに一見あやしく見える動き」を必ず入れる（例：道具を取りに出口の方へ歩いてから戻る）。これがないと「出口に歩いた＝あやしい」と機械が丸暗記しただけの結果になり、発表で突っ込まれる

## 2. 試し撮り（7月後半）

- 部屋に机・棚・小物を置いて撮影環境を作る
- カメラの置き場所を試行錯誤する。**しゃがんだ時や後ろを向いた時でも体全体がちゃんと映る位置**を見つけるのが目的
- 自分で2〜3本演技して撮り、プログラムに通してみて、体の動きがきちんと読み取れているか確認する
- うまくいったら、カメラ位置と台本を「凍結」する（以後変えない）

## 3. 本番の撮影（8月〜9月）

- 協力者を3人、できれば5人集めて日程を調整する（ここが一番時間がかかるので早めに声かけ）
- 1人あたり30本ほど、合計90〜150本を撮る。撮影自体は2〜3日で終わる
- 撮ったその日に必ずプログラムに通して、読み取り失敗がないか確認する（後でまとめてやると撮り直しがきかない）

## 4. 動画への印つけ（9月〜10月）

- 各動画について、手作業で記録する：どの物をいつ触ったか、物の位置、作業場所の範囲
- **守るルール**：「返した／返してない」のような答えそのものは書き込まない（機械に答えを教えてしまうことになり、実験が無意味になる）。物が画面から消える動画は、最後に「見えなくなった」と印をつける
- 単純作業なので、音楽でも聴きながら毎日少しずつ

## 5. 実験と分析（10月〜11月）

- 実験はコマンドを実行して待つだけ。自分の仕事は**結果を読むこと**
- 見るポイント：
  - 前後の様子まで見る方式は、瞬間だけ見る方式より本当に当たっているか
  - どれくらい早い時点で「あやしい」と気づけたか
  - **間違えた動画を1本ずつ見直して、なぜ間違えたかを言葉にする**（発表で一番評価される部分）
- 「ズルで当てていないか」の確認：出口に歩くだけのふつう動画がちゃんと「ふつう」と判定されているかを見る

## 6. 執筆と発表準備（12月〜1月）

- 論文の下書き（論文_プロト_v2.md）は骨組みができているので、結果の数字と図を埋めていく
- 「なぜ体の動きだけを使うのか？」への答えは `docs/プライバシー配慮_根拠資料.md` にまとめてある。発表の冒頭に組み込む
- 正直に書くこと2点：
  - 体の動きのデータだけでも、歩き方から人を特定できてしまう可能性はある（完璧な匿名化ではない）
  - 実験は「あやしい役の演技」なので、本物の犯罪を見抜けると断定はしない

## やらないこと（手を出すと終わらない）

- リアルタイム処理、スマホ連携、複数人対応、いろんな家での実験、物の自動検出の精度向上
- これらは論文の「今後の課題」に一行書けば十分

## 合言葉

**7月に環境を固め、9月に撮り終え、11月に分析を終え、12月から書く。** 迷ったら「実験が1本回りきること」を最優先。
